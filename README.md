# One-Line Roast: The Gadget You Use Every Day

A [make.fun](https://make.fun/bounty/u-daring-gecko-25-one-line-roast-the-gadget-you-use-3d6aa610) bounty entry. `main.py` (Python 3.13, stdlib-only) writes a single original one-line roast of a gadget used every day to `/output/entry.txt`:

> My smartwatch congratulates me for standing up once an hour, like a fitness coach who thinks my job is sitting professionally.

Run it with `python3 main.py`. The output is deterministic: exactly one line, 126 characters, UTF-8.
